# Original preservation checklist

The 83 original file blobs and modes match the source baseline. The following runtime checks remain unverified because supported browser tooling is unavailable; do not mark them passed from hashes alone.

For desktop, narrow mobile, tablet, short viewport and reduced-motion configurations:

- [ ] Solar journey: orbit positions, pointer response, destination buttons, camera transitions, scale notes and loading fallback.
- [ ] Signal page: sticky eligibility, tall-layout scrolling, scanner 5.5s, waveform 2.4s, beacon 3s, reading hold 1.4s and scroll handoff.
- [ ] Story Orbit: all six cards, gathering motion, disc transition, all 30 slides and overview return.
- [ ] Every mission’s headline words, facts, image motion, legacy slide, timeline and end card.
- [ ] Full-screen reader: previous/next, keyboard, swipe, close, focus restoration and backdrop behavior.
- [ ] Five-second idle navigation nudge and 1.8s glow.
- [ ] Monochrome background 160s rotation and 70s drift, pause and hidden-tab behavior.
- [ ] Archive: search, all/Moon/Mars filters, empty/reset state, 420ms staggered rows, 460ms filter-orb and hover/focus transitions.
- [ ] Surface chronology: counters, chart layout, 1.3s bar growth, stagger, 26s drift and 2.6s beacon.
- [ ] Menu: links, Escape, keyboard focus cycle and body scroll lock.
- [ ] Sources dialog: attribution, external links, close and focus.
- [ ] All illustrations, planetary detail levels, typography, spacing and responsive breakpoints.
- [ ] Root and `/explore/` coexist without global CSS or event-listener crossover.

Use the exact original commit and imported baseline under identical viewport, date, storage and motion settings. Compare animation sequences as well as static screenshots; date-derived counters must be compared on the same date.
